# Amazon Clone - Home Page

<br>
This project is a static clone of Amazon's landing (home) page, created using only HTML and CSS. It replicates the look and structure of the Amazon website’s front page, including the header, navigation bar, product sections, and footer. This project is ideal for practicing frontend development and understanding layout design with CSS.
<br>


📌 Features

-> Responsive header with Amazon logo, search bar, and navigation links

-> Fully structured product sections with sample category cards

-> Styled using clean, modular CSS

-> Footer section with useful links and information

-> Mobile-friendly layout using basic responsive techniques

<br>

💻 Technologies Used

-> HTML5
<br>
-> CSS3

<br>

📚 Learning Purpose

This project was created to:

-> Practice frontend skills using HTML and CSS

-> Understand real-world web layout structures

-> Recreate a widely used e-commerce design
